3. IMPORTANT: PACKER USAGE
Make sure you are NOT returning empty buffer

WRONG:

CORRECT:
const buffer = await Packer.toBuffer(doc);
res.setHeader("Content-Type", "application/vnd.openxmlformats-officedocument.wordprocessingml.document");
res.setHeader("Content-Disposition", "attachment; filename=psv-report.docx");
res.send(buffer);

4. ASYNC ISSUE (VERY COMMON BUG)
Ensure await is used:

a.click();
